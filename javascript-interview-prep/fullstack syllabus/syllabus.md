## Projects

By the time you're interviewing, I'd want to see projects like:

Job Tracker (finish deployment)
E-commerce App
Chat Application (WebSockets)
Project Management Tool (Trello/Jira style)
Real-time Dashboard (charts, filters, pagination)
AI-integrated application (using an LLM API)
How to practice

For every topic:

Learn the concept.
Build a small feature with it.
Explain it out loud as if you're teaching someone.
Solve interview questions on it.
Revisit it after a few weeks.

That repetition is what builds confidence.
